# xleader-cwi v0.2 — Kế hoạch triển khai tinh gọn

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Biến xleader-cwi từ plugin ~800 dòng JS thành plugin không có dòng code nào — khai thẳng MCP gốc của Metabase, giữ lại đúng phần tri thức nghiệp vụ và kỷ luật trả lời.

**Architecture:** `plugin/.mcp.json` khai remote MCP `https://insight.xteam.edu.vn/api/metabase-mcp` (HTTP + OAuth 2.1, Claude Code tự lo xác thực). Mọi truy vấn đi qua tool `execute_sql` của server đó. Tri thức nghiệp vụ nằm trong `plugin/knowledge/`, kỷ luật trả lời nằm trong hai SKILL.md. Không còn tool `cwi_*`, không còn guardrail trong code, không còn snapshot cấu trúc dữ liệu.

**Tech Stack:** Markdown + JSON. Không có ngôn ngữ lập trình nào. Metabase v0.63.14.2, Postgres, MCP protocol.

**Spec:** `docs/superpowers/specs/2026-08-24-tinh-gon-v02-design.md` — đọc trước khi bắt đầu bất kỳ task nào.

- **Mọi SQL lọc `"deletedAt" is null`** trên mọi bảng tham gia — toàn hệ thống dùng xoá mềm.
- **Prod:** `https://insight.xteam.edu.vn` · `database_id = 2` · schema `workspace_6ytci89jf3kflsl9aaaxrr5hw` (đo 24/08: 883 cột).

- **Mọi thao tác GHI lên prod phải hỏi người dùng trước, mỗi lần.** Kế hoạch này được thiết kế để KHÔNG cần ghi lên prod.

- [ ] **Bước 3: Viết 7 khối SQL nháp**

Dưới đây là nháp đã theo đúng 10 quy tắc trong `business-rules.md`. `WS` = `workspace_6ytci89jf3kflsl9aaaxrr5hw`.
**Chưa được ghi vào file** — Bước 4 đối soát xong mới ghi. Khi ghi vào file phải thay `WS` bằng tên schema thật `workspace_6ytci89jf3kflsl9aaaxrr5hw`, không để chữ viết tắt trong tài liệu người sau đọc.

**1. Doanh thu NET (chưa VAT), theo ngày tổ chức lớp**
```sql
select date_trunc('month', c."ngayToChuc")::date as thang,
       round(sum(oi."thanhTienAmountMicros" / (1 + coalesce(oi."vat", 0)) / 1e6)) as doanh_thu_net
  from "WS"."_orderItem" oi
  join "WS"."_order"     o on o.id = oi."donHangId"  and o."deletedAt" is null
  join "WS"."_class"     c on c.id = oi."lopHocId"   and c."deletedAt" is null
 where oi."deletedAt" is null
 group by 1 order by 1
```

**2. Số vé bán**
```sql
select sum(oi."soLuong")::int as so_ve
  from "WS"."_orderItem" oi
  join "WS"."_order" o on o.id = oi."donHangId" and o."deletedAt" is null
 where oi."deletedAt" is null
```

**3. Ghi danh chính thức**
```sql
select count(*)::int as ghi_danh_chinh_thuc
  from "WS"."_enrollment" e
 where e."deletedAt" is null and e."trangThai" = 'CHINH_THUC'
```

**4. Cơ hội theo tầng phễu**
```sql
select o."phanLoaiLead" as tang, count(*)::int as so_co_hoi
  from "WS"."opportunity" o
 where o."deletedAt" is null
 group by 1 order by 1
```

**5. Phân loại kênh**
```sql
select case when o."nguon" is null then 'Nguồn chưa rõ'
            when o."nguon" like '%ADS' then 'Paid Sale'
            else 'Organic Sale' end as kenh,
       count(*)::int as so_co_hoi
  from "WS"."opportunity" o
 where o."deletedAt" is null
 group by 1 order by 2 desc
```

**6. Lớp học**
```sql
select c."maLopHoc", k."tenKhoaHoc", c."ngayToChuc", c."siSoMucTieu",
       count(e.id) filter (where e."trangThai" = 'CHINH_THUC')::int as si_so_chinh_thuc
  from "WS"."_class" c
  left join "WS"."_course"     k on k.id = c."khoaHocId"    and k."deletedAt" is null
  left join "WS"."_enrollment" e on e."lopHocId" = c.id     and e."deletedAt" is null
 where c."deletedAt" is null
 group by 1,2,3,4 order by c."ngayToChuc" desc nulls last limit 50
```

**7. Đối tác doanh nghiệp**
```sql
select cty."name" as cong_ty,
       count(distinct e."hocVienId")::int as so_hoc_vien,
       count(e.id)::int                   as so_luot_ghi_danh
  from "WS"."_enrollment" e
  join "WS"."person"  p   on p.id = e."hocVienId" and p."deletedAt" is null
  join "WS"."company" cty on cty.id = p."companyId" and cty."deletedAt" is null
 where e."deletedAt" is null and e."trangThai" = 'CHINH_THUC'
 group by 1 order by 2 desc limit 50
```

select op."maOpp",

   and o."createdAt" >= date_trunc('week', current_date) - interval '7 days'

   dừng và hỏi lại. Mọi năng lực kỹ thuật đến từ MCP gốc của Metabase.
2. **Mọi SQL ghi đủ `"<schema>"."<bảng>"`** và lọc `"deletedAt" is null` trên mọi bảng tham gia.
3. **Không đóng gói snapshot cấu trúc dữ liệu vào repo** — cấu trúc đọc sống bằng `information_schema`.
4. **Mọi thao tác GHI lên prod phải hỏi người dùng trước, mỗi lần.** Prod là hệ thống LIVE đang điều hành

5. **SQL chạy được ≠ số đúng.** Mọi con số công bố phải đếm lại bằng một đường độc lập.
